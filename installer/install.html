EX메일 익스플로러

__RELEASE__ · 첨부 v18.2를 복원한 수정판

내부 PC와 외부 PC에
각각 설치하세요

같은 설치 파일을 양쪽에서 실행합니다. 업데이트 전에는 기존 EX메일 PowerShell 창을 종료하세요. 브라우저 탭만 닫으면 프로그램은 계속 실행됩니다.

설치 · 두 단계

  1. 아래 버튼을 눌러 설치 BAT를 다운로드합니다.
  2. 다운로드한 BAT를 실행하세요. C:\EX메일 익스플로러에 설치하고 완료 후 EX메일 화면을 바로 엽니다.

HTML을 여는 것만으로는 설치되지 않습니다. 내려받은 BAT를 실행하세요.

처음 한 번만 설정

각 PC의 역할·실제 수신 폴더를 고르세요. 자료교환 위치 설정이 없으면 안내 팝업이 뜹니다.

위치 설정 시작 → ＋·열기·보내기 위치 지정 → 테스트 전송

수신 폴더가 확인되지 않았다면 폴더 설정부터 시작합니다. 자료교환 프로그램을 열고 보내기 목록을 비워 두세요. 실제 설정은 내부·외부에서 각각 진행해야 합니다.

재부팅 후 자동 복구·실행

시작프로그램에 EXMail-Recover.bat를 보관합니다. 파일이 정상적이면 바로 실행하고, 설치 폴더가 없어졌거나 프로그램 파일이 손상됐으면 복구 후 실행합니다.

역할·수신 경로는 복구 설정에 보관합니다. 메일·AI 키·브라우저 로그인 자료는 여기에 복사하지 않습니다. 시작프로그램 폴더나 사용자 데이터까지 초기화되는 PC에서는 해당 자료의 유지가 보장되지 않습니다. C: 쓰기 권한이 없으면 복구 실패 메시지가 표시됩니다.

자동 실행 해제: Win+R → shell:startup → EXMail-Recover.bat 삭제

연결 확인 파일 정리

처리 완료한 연결 요청·응답·성공 기록은 자동 삭제합니다. 외부 전송 프로세스 종료와 대기 시간을 확인한 후 정리하며, 오류는 logs/errors-날짜.jsonl에 단계·코드만 남깁니다.

수동 설치용 ZIP

자동 복구·바로가기 등록을 사용하려면 위 BAT로 설치하세요.

AI 웹 질의는 시험 기능입니다. 실제 AI 계정·Windows·i-oneNet 환경의 동작은 해당 PC에서 확인해야 합니다. 기존 메일/첨부 전체 암호화는 이번 수정 범위에 포함되지 않습니다.
