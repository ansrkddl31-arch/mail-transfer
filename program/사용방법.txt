EX메일 익스플로러 v18.2 복원 수정판 (v18.2-r1)

이 설치본은 사용자가 제공한 v18.2 자동설치 BAT의 34개 원본 프로그램 파일을 복원한 뒤 수정했습니다.
v17.2 소스와 비교했으며 AI 질의·일정·메일 기능을 v17.2로 되돌리지 않았습니다.

설치/업데이트
1. 내부·외부 PC의 기존 EX메일 PowerShell을 종료합니다.
2. 양쪽 PC에서 설치 HTML → BAT 다운로드 → 해당 BAT 실행.
3. C:\EX메일 익스플로러에 설치/검증 후 EX메일 화면이 즉시 열립니다.
4. 위치 설정이 없으면 안내 팝업의 위치 설정 시작을 누르세요.
   수신 폴더가 확인된 PC에서는 위치 지정과 테스트 전송을 바로 시작합니다.
   미확인 PC는 수신 폴더를 먼저 저장해야 합니다.
   시작은 테스트 파일 1개 전송에 대한 실행입니다. 자료교환을 열고 보내기 목록을 비워 두세요.

재부팅 후 자동 실행/복구
- 시작프로그램에는 자체 프로그램 ZIP을 포함한 EXMail-Recover.bat가 등록됩니다.
- 정상 파일은 그대로 실행합니다. 누락/손상이 있으면 프로그램을 복구한 뒤 EX메일 화면을 엽니다.
- 바탕화면 바로가기도 이 BAT로 연결되어 설치 폴더가 삭제돼도 복구할 수 있습니다.
- 역할/수신 경로/개수는 Startup 옆 EXMailRecovery/settings.json에 별도 저장합니다.
- 해당 백업에는 비밀번호·메일·AI 키·브라우저 로그인 자료를 넣지 않습니다.
- 메일, API 키, 위치 설정, 브라우저 로그인은 기존 사용자 데이터 폴더의 자료를 사용합니다.
  사용자 데이터까지 초기화되는 PC에서는 다시 설정/로그인이 필요합니다.
- 시작프로그램 폴더까지 지워지는 환경에서는 복구 BAT도 사라집니다. 그 경우 유지되는 경로가 필요합니다.
- C: 쓰기 권한이나 보안 정책으로 실행이 차단되면 실패 메시지와 오류 로그를 확인하세요.
- 자동 실행 해제: Win+R → shell:startup → EXMail-Recover.bat 삭제.

연결 확인 파일 정리
- 처리 완료한 연결 요청·응답, 중복 수신본, 전송 부속 파일, 성공 상태·추적 파일을 삭제합니다.
- 외부 전송은 생산 프로세스 종료와 15초 대기 후 정리합니다. 잠긴 파일은 다음 주기에 다시 처리합니다.
- 실패 정보는 logs/errors-날짜.jsonl에 시간·단계·코드·요청ID만 기록합니다.
- 사용자 파일/보관 중인 메일·첨부파일·설정은 삭제하지 않습니다.
- 완료 여부를 확인할 수 없는 작업은 임의로 성공 처리하지 않습니다.

기존 기능 안내

v18.2-r1 자료교환 초기 설정 바로가기

내부·외부 PC 상단의 자료교환 초기 설정 버튼을 누르세요.
미설정 PC에는 메인 화면에 노란 안내와 초기 설정 시작 버튼이 표시됩니다.
수신 폴더 확인 → 저장하고 다음 → 자료교환 ＋·보내기 버튼 위치 지정 → 테스트 전송 순서로 진행합니다.
양쪽 PC에서 각각 설정해야 합니다. 완료 후에는 상단의 자료교환 설정 버튼으로 다시 설정할 수 있습니다.
처리 중에는 상단 대기 취소로 작업을 종료한 뒤 설정하세요.

v18.2-r1 무반응 확인 및 수정

- 내부·외부 기존 PowerShell을 종료하고 양쪽 모두 이 버전으로 설치/실행하세요.
- 상단 대기 취소/작업 중지는 항상 표시됩니다. 작업이 없을 때만 비활성화합니다.
- 내부 AI 탭은 외부 연결 전에도 열립니다. AI 선택 시 로그인 안내가 즉시 표시됩니다.
- 외부 화면의 ChatGPT / Claude / Gemini 열기·확인은 자료교환 없이 직접 브라우저를 실행하고 결과 코드를 표시합니다.
- 우선 외부에서 ChatGPT 열기·확인 → 전용 Edge에서 직접 로그인·2차 인증을 완료하세요.
- 내부 AI 로그인 팝업에서 외부 연결 확인 → 외부 버전·AI 웹 지원 확인 → 이미 로그인함/모델 확인을 누르세요.
- AI 요청 생성/자료교환 전송/외부 응답 대기를 구분해 표시합니다. 전송 실패 메시지도 팝업 안에 표시합니다.
- 외부가 AI 요청을 지원하는지 확인되지 않으면 요청을 전송하지 않고 업데이트·재연결 안내를 표시합니다.
- 로그인 열기/모델 확인 응답은 전송 제출 후 최대 3분 대기하며 시간초과하면 실패를 표시합니다.
- 실제 AI 계정·Windows/i-oneNet 실행 검증은 별도로 필요합니다. 브라우저 직접 점검도 실패 결과를 그대로 표시합니다.

EX메일 익스플로러 v18.2-r1 · AI 웹 질의 시험 기능

1. 내부·외부 PC 모두 설치하고 기존 PowerShell을 종료한 뒤 새 시작.bat 실행.
2. 양쪽 자료교환과 수신 경로·보내기 초기 설정을 확인하고 내부에서 외부 연결.
3. 내부의 AI에게 질의하기 → ChatGPT / Claude / Gemini 선택.
4. 외부 로그인 열기 → 외부 PC의 전용 Edge에서 직접 로그인.
5. 내부에서 이미 로그인함 → 실제 로그인 상태와 모델 메뉴 확인.
6. 질문·모델·첨부파일 선택 → 질문 보내기. 모델 목록이 없으면 외부 현재 모델을 사용.
7. 답변과 생성 파일 다운로드 버튼을 내부에서 확인. 파일 실패는 답변과 별도 표시.
8. 대화 이력은 내부 PC에 Windows 사용자 암호화(DPAPI)로 저장. 새 대화·선택·삭제 지원.

범위 및 제한
- 실제 웹서비스 계정으로 원격 검증한 완제품이 아닌 시험 기능입니다. 추가 인증은 직접 진행하세요.
- 웹 화면·계정·언어 변경으로 요소 탐색이 실패할 수 있습니다. Claude 아티팩트 전용 화면과 Gemini Docs 내보내기는 별도 지원이 필요할 수 있습니다.
- 질문 첨부/생성 파일은 각각 최대 3개, 합계 5MB. 파일 입력과 업로드 완료가 확인되지 않으면 질문을 보내지 않습니다.
- 답변 완료는 스트리밍 종료·응답 버튼·텍스트 안정 상태를 함께 확인합니다. 완료를 확인하지 못하면 실패로 반환합니다.
- 후속 질문은 이전 텍스트 대화를 새 외부 대화에 전달합니다. 이전 첨부파일을 재사용하려면 다시 첨부하세요. 외부 사이트의 대화와 일대일 동기화되는 구조는 아닙니다.
- API 제공업체 설정과 AI 웹 질의는 별개입니다. 모델은 실제 화면에서 확인한 항목만 사용합니다. 연구 모드·도구 등 전체 서비스 기능을 복제하지 않습니다.
- 서비스 이용 제한·구독 조건은 해당 계정에 따릅니다. 질문/첨부는 선택한 외부 AI 서비스로 전달됩니다.
- 이 버전의 신규 AI 질의 파일은 질문·답변·첨부·생성 파일을 암호화하고 무결성을 확인합니다.
- 기존 메일/메일 첨부 전송 전체 암호화는 이 버전에서 변경하지 않았습니다. 로그인 자격 증명만 기존 암호화를 유지합니다.
- 연결 키는 기존 자료교환 키 교환을 신뢰합니다. 별도 인증서 기반 상대 인증은 구현하지 않았습니다.
- 대기 취소는 내부 대기만 취소합니다. 이미 전달된 외부 작업은 외부 PC에서 F4로 중지하세요. 자동 재전송하지 않습니다.
- 생성 파일은 내부에 암호화 보관하며 다운로드 버튼을 누르면 선택한 저장 위치에 원본 파일로 저장됩니다.
- 이력 삭제는 내부 이력과 해당 생성 파일을 삭제합니다. 외부 AI 서비스의 대화/첨부는 직접 삭제해야 합니다.

기존 메일 기능 안내

필수: 내부 PC와 외부 PC 양쪽에 각각 설치해야 합니다.

EX메일 익스플로러 v18.2-r1 · 빠른 사용 안내

처음 한 번 (양쪽 PC)
1. 설치 HTML에서 프로그램 저장. 업데이트면 기존 프로그램을 닫고 같은 폴더 선택.
2. 저장한 폴더의 시작.bat 실행.
3. 양쪽 모두 PC 역할 → 실제 자료교환 수신 폴더 → 보내기 초기 설정.
   내부·외부 양쪽에서 시작.bat와 자료교환 프로그램을 실행해 두세요.
   수신 폴더 예: 내부 D:\FTC_downloads / 외부 C:\FTC_downloads. 실제 저장 경로와 일치해야 합니다.
   전송이 안 되면 양쪽 모두 설정 → 저장하고 다음 → 보내기 초기 설정 · 테스트 전송을 다시 진행하세요.
   기존 폴더·개수·버튼 위치·메일은 그대로 유지합니다.

평소
내부 ‘다시 불러오기’ → 필요할 때만 외부 생체 인증 → 내부에서 메일 확인.
이미 로그인했다면 로그인 버튼을 먼저 누를 필요는 없습니다.
외부 PC는 프로그램·자료교환을 켜둔 상태여야 합니다.
중지: 작업 중인 PC에서 F4. 전송 직전에만 입력을 제한합니다.

메일 개수·날짜와 목록 페이지
수집 기준: 최근 개수 또는 받은 날짜 범위(한국 시간, 시작·종료일 포함).
범위 수집은 받은메일함 페이지를 넘기며 해당 기간의 메일을 최대 지정 개수까지 가져옵니다.
기간 내 최대 개수에 도달하면 안내합니다. 날짜를 읽지 못한 메일은 제외 내역으로 표시합니다.
해당 기간의 메일이 없으면 0건으로 완료합니다. 첨부 다운로드 날짜가 아닌 메일 받은 날짜 기준입니다.
조건 저장·개수 저장은 다음 요청에 적용하며 자동 수집하지 않습니다.
내부 받은 메일 목록은 기본 20개씩 표시하고 아래에서 페이지 이동·10/20/50개씩 표시를 고를 수 있습니다.

AI는 선택
외부 AI 설정: 사용할 서비스의 API 키를 한 번 등록하고 사용을 허용합니다.
Gemini / OpenAI / Claude / DeepSeek / OpenRouter / xAI / Groq를 선택할 수 있습니다.
그 밖에는 직접 등록에서 OpenAI 호환 API 전체 주소·모델·키를 설정하세요.
모든 AI를 제한 없이 지원하는 것은 아니며 해당 서비스에 Chat Completions 호환 API가 있어야 합니다.
Ollama / LM Studio는 외부 PC의 로컬 서버를 실행하고 모델을 지정합니다. API 키 없이도 가능합니다.
JSON 모드가 없으면 고급 설정에서 프롬프트 방식을 선택하세요. JSON 응답 해석 실패 시 원문만 전달합니다.
내부 AI 설정: AI 사용 켜기·끄기, 사용할 AI, 요약 개수(1~100), 일정 후보 추출 켜기·끄기.
설정 저장은 다음 수집부터 적용하며 저장만으로 새로 수집하지 않습니다.
API 키는 외부 PC의 현재 Windows 사용자로 암호화 저장합니다.
활성화한 요청에서 외부 PC가 메일 제목·보낸 사람·본문을 선택한 AI로 전송합니다.
사용 요금과 한도는 해당 AI 서비스의 키에 적용됩니다.
AI가 실패해도 메일 원문·첨부는 전달합니다. 성공한 요약은 캐시를 재사용합니다.
본문 6,000자를 넘는 긴 메일은 앞부분 기준임을 표시합니다.
한 번의 AI 처리에는 시간 한도가 있으며 초과한 나머지 메일은 원문으로 전달합니다.

일정
메일의 일정 후보 → 확인하고 일정 등록 → 날짜·시간·제목 확인 → 저장.
나의 일정에서 직접 추가·수정·완료·삭제가 가능합니다.
일정은 내부 PC에 저장하며 프로그램을 재시작해도 유지합니다.
원문 근거가 없는 날짜나 지난 날짜는 AI 후보로 넣지 않습니다.
AI 요약과 일정 후보는 참고용이며 최종 확인은 사용자가 합니다.

문제가 생기면
외부 화면의 현재 단계·처리 위치·제한시간 확인 → 진단 다운로드.
전송 여부가 불확실하면 실제 수신 여부를 확인하고 다시 요청합니다.
폴더 설정: 내부 기본 D:\FTC_downloads / 외부 기본 C:\FTC_downloads.
첨부: 가져오기 → 내부 도착·검증 후 저장. 최종 파일명은 원래 이름 유지.
메일에 포함된 MIME 첨부 8MB 이하 지원. 대용량 외부 링크는 지원하지 않습니다.
처음 입력 보호를 쓸 때는 입력보호확인.bat로 F4 해제를 확인하세요.
설정·일정 데이터가 읽히지 않으면 기존 파일을 덮어쓰지 않고 오류를 표시합니다.

실제 앱에 둥근 카드·빨강/청록 UI와 받은 메일 / AI 브리핑 / 나의 일정 탭을 적용했습니다.
앱 상단에 앱 v18.2-r1이 보여야 새 버전입니다. 기존 프로그램 PowerShell을 닫고 새 바로가기로 실행하세요.

연결 초기화 (v18.2-r1)
