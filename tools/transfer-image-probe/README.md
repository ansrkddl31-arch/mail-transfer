# 자료교환 이미지 인식 시험 준비본

기존 EX메일에는 적용하지 않은 별도 진단 도구입니다. 실제 클릭, 경로 입력, 파일 전송, 설정 변경은 하지 않습니다. Windows PowerShell 5.1과 .NET 기본 기능을 사용하며 설치할 별도 EXE는 없습니다.

## 시험 방법

1. ZIP을 풀고 자료교환 창을 엽니다. 창 전체가 화면 안에 보이게 둡니다.
2. `이미지인식진단.bat` 실행 후 **8초 안에 자료교환 창을 클릭**합니다. 캡처할 때 그 창이 맨 앞에 있어야 합니다.
3. 열린 결과 폴더의 `candidates.png`에서 빨간 사각형이 실제 ＋를 정확히 둘러싸는지 봅니다.
4. 직접 시험 파일 하나를 등록하고 같은 BAT를 다시 실행합니다. 이번에는 보내기 버튼 후보를 확인합니다. **보내기를 누를 필요는 없습니다.** 파일은 시험이 끝나면 직접 등록 취소하세요.

배율 100%, 125%, 150%에서 필요에 따라 반복할 수 있습니다. 결과는 실행별 logs 하위 폴더의 capture.png, candidates.png, result.json에 남으며 실패하면 error.txt가 남습니다. 후보가 0개이거나 여러 개이거나 위치가 틀려도 임의로 클릭하지 않습니다.

캡처에는 자료교환 창의 사용자명·파일명·받기 목록이 포함될 수 있습니다. 자동 업로드는 하지 않습니다. 공유할 때는 가리거나 빈 시험 파일로 확인하세요. 로그는 직접 지울 수 있습니다.

현재 방식은 제공된 화면의 원형 ＋ 모양과 하단 청록색 사각 버튼을 찾는 **형태·색상 기반 시제품**입니다. 글자 OCR이나 학습된 물체 인식이 아니며 점수는 성공 확률이 아닙니다. 다른 비슷한 아이콘/버튼도 후보가 될 수 있으므로 실제 화면 결과를 확인한 뒤에만 다음 자동화 여부를 판단합니다. 창을 찾지 못하거나 다른 창이 맨 앞이면 캡처를 중단합니다.

스크린샷만 검사하려면 PowerShell에서 `Test-ImageRecognition.ps1 -ImagePath "C:\경로\화면.png"`를 실행합니다. 자동으로 만든 결과 폴더에만 파일을 씁니다.

검증: Detector.cs의 실제 픽셀 매칭 코드는 합성 이미지에서 여러 배율의 ＋·청록색 버튼, 다른 회색 도형·청록색 원·빈 화면을 검사합니다. Windows 화면 캡처 및 실제 i-oneNet 인식률은 아직 확인하지 않았습니다.
