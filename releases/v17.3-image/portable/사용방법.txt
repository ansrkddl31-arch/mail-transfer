EX메일 익스플로러 · 포터블 v17.3 이미지4

1. 내부 PC와 외부 PC 각각에 ZIP 전체를 압축 해제하세요.
2. 압축 푼 폴더의 EX메일 실행.exe를 실행하세요.
3. 처음 한 번 각 PC의 역할과 자료교환 수신 폴더를 설정하세요.
4. 양쪽 자료교환 프로그램을 켜 두고, 내부에서 '로그인하고 불러오기'를 누르세요.
   첫 요청에서 연결을 준비하고, 이미 웹메일에 로그인했으면 바로 수집합니다.
   로그인이 필요하면 화면 안내에 따라 외부에서 생체 인증을 완료하세요.

실행 중인 PowerShell 창을 켜 두세요. 외부 PC는 대기 상태로 실행됩니다.
화면을 다시 열려면 EX메일 실행.exe를 한 번 더 실행하세요.
종료할 때는 자료교환 작업을 F4로 중지한 뒤 PowerShell 창을 닫으세요.
브라우저 탭만 닫으면 백엔드는 계속 실행됩니다.

이 배포본은 C드라이브 설치, 바탕화면 바로가기, 시작프로그램 등록을 하지 않습니다.
설정·메일·일정·로그인 프로필은 data, 오류 로그는 program/logs에 저장합니다.
메일 첨부파일은 기존과 같이 보존합니다. 자료교환 수신 폴더는 별도로 설정한 경로입니다.
다른 폴더로 옮길 때는 프로그램과 자동화 Edge를 종료한 뒤 폴더 전체를 옮기세요.
로그인 프로필과 API 키 보호는 Windows 사용자·PC에 종속될 수 있으므로 다른 PC에서는 다시 로그인·설정하세요.
기존 설치판의 설정을 자동으로 가져오거나 덮어쓰지 않습니다.

이미 설치판/다른 포터블판이 실행 중이면 기존 PowerShell을 종료한 뒤 실행하세요.
같은 PC에서 두 프로그램을 동시에 실행할 수 없습니다(8765 포트).
ZIP 안에서 EXE만 꺼내거나 ZIP 미리보기 안에서 바로 실행하지 마세요.
업데이트할 때는 프로그램을 종료하고, data 폴더를 보존한 채 프로그램 파일만 교체하세요.

Windows 64비트, Windows PowerShell 5.1, Edge/Chrome 및 자료교환 프로그램이 필요합니다.
별도 .NET·WebView2 설치나 앱 실행 시 프로그램 다운로드는 하지 않습니다.
HTML만 단독 실행하는 배포본은 아니며 EXE가 기존 PowerShell 백엔드를 실행합니다.

Windows의 다운로드 차단이 표시되면 ZIP 속성의 '차단 해제'가 허용되는지 확인한 뒤 새로 압축 해제하세요.
이 EXE는 코드 서명되지 않았으며 회사 정책에서 실행을 차단할 수 있습니다.
실행 정책이나 보안 설정을 강제로 해제하지 않습니다. 정책 차단 시 담당자의 실행 허용이 필요합니다.

개발 환경에서는 실행 계획·상태 보존·실제 HTTP 동작과 Windows EXE 형식을 검사했습니다.
실제 Windows에서 EXE 실행·자료교환 클릭·보안 정책 통과는 별도 확인이 필요합니다.
