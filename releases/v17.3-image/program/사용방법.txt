EX메일 익스플로러 v17.3 · 이미지 자동 전송

1. 내부·외부 PC 각각 자동설치 BAT를 실행하세요. 기존 PowerShell은 먼저 종료합니다.
2. 양쪽 역할과 자료교환 실제 수신 폴더만 설정하세요. 버튼 좌표는 찍지 않습니다.
3. 양쪽 자료교환을 켜고 로그인해 두세요. 보내기 목록은 비워 두세요.
4. 내부에서 외부 연결 → 로그인하고 불러오기. 필요하면 외부에서 생체 인증합니다.
5. 설정의 이미지 자동 인식 · 시험 전송으로 별도 TXT 한 개를 보내 확인할 수 있습니다.

자료교환 클릭 직전부터 입력을 제한합니다. F4로 중지하세요.
보내기를 누른 뒤 실패했다면 반대쪽 수신 여부부터 확인하고 다시 요청하세요.
다른 파일이 등록돼 있으면 자동으로 비우지 않습니다. 직접 취소한 뒤 다시 시도하세요.
전송 실패 단계와 코드는 진단 다운로드 또는 설치 폴더 logs에 남습니다.
