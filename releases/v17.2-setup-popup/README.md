# EX메일 익스플로러 v17.2 · 위치설정 수정1

기준은 사용자가 다시 제공한 v17.2 설치 HTML입니다. 내장 프로그램 30개 중 app.html만 수정했습니다. 기존 CSS, 상단 버튼, 탭, 메일·일정 기능, 설치 방식과 나머지 29개 파일을 그대로 유지합니다. v18.2 AI 웹 질의·복구·정리 기능은 포함하지 않습니다.

내부·외부 PC 모두 역할 선택 후 자료교환 위치가 미설정이면 안내 팝업이 뜹니다. 수신 폴더가 이미 확인됐으면 시작 버튼으로 기존 위치 지정·시험 전송을 바로 실행합니다. 폴더가 미확정이면 먼저 기존 폴더 설정 단계를 엽니다. 시험 파일 1개가 실제 전송된다는 안내가 포함되어 있습니다. 나중에를 누르면 해당 역할에서 같은 실행 중 반복 안내하지 않으며, 기존 설정 메뉴는 계속 사용할 수 있습니다.

기존 프로그램 PowerShell을 종료하고 양쪽 PC에 수정판을 설치하세요. 기존 설치 HTML의 폴더 저장과 BAT 자동설치 방식을 유지했습니다. 브라우저 탭만 닫으면 기존 백엔드는 계속 실행됩니다.

빌드: `python build.py`. 산출물은 dist/에 생성합니다. 빌드는 다른 29개 파일이 원본과 동일한지 검사합니다.

검증: Node.js 및 jsdom 24.1.3으로 `node tests/setup-popup.cjs`. 팝업·설정 진입·시험 전송 HTTP 요청을 검증하며 Windows의 실제 위치 지정·자료교환 전송은 모의 처리합니다.
